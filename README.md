# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 权重敏感性试探

结果页可选择任一价值维度，查看它的归一化权重在 0–100% 之间变化时建议在哪些位置转折，并把滑块临时停在任意位置与当前权重并排对比；试探不修改原权重，确认“套用”才写回并重新推演，重新编辑方案后旧敏感性结果立即失效。

提高一个维度必然挤占其余维度，提供三种可解释的分摊方式：按当前比例分摊（默认；当前只看该维度时退化为均摊）、指定一个维度承担（它被压到 0 后不足部分再按比例分摊）、其余三维均摊。路径上的权重仍走同一份归一化与评分规则。

转折点寻找方法对比（详见 `docs/superpowers/specs/2026-10-07-weight-sensitivity-design.md`）：

- **固定步长扫描**：实现简单，但宽度小于一个步长的区间（窄并列带、两次相邻翻转）会被整格跨过，精度与计算量线性对冲（步长 5% 需 21 次评分，1% 需 101 次，0.1% 需约 1001 次）。
- **逐步细化（粗扫 + 局部二分）**：只在“格子两端状态不同”时加密，转折少时更省、定位更准；但被粗格整格跨过的窄区间两端状态相同，细化永不触发——盲区由粗步长决定，不由容差决定。
- **结构枚举（本应用采用）**：评分函数在权重路径上分段仿射、整数总分只在舍入边界跳变，因此枚举全部折点后在区间中点各做一次真实评分即可无遗漏分段，且成本与显示精度无关。名次一律调用真实评分，不用图形交点插值猜胜者；差距 &lt;5 的接近是一种一等“并列状态”，窄并列带与精确折点上的孤立状态都会显示。5 分边界附近由一位小数归一化产生的 0.0x 百分点微抖动会并入显示分带，但精确切换点仍在“边界微切换”明细中列出。

# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。结果页支持权重敏感性分析：选定一个维度扫描 0–100%，定位建议转折点与并列区间，并可临时套用任意权重对比、确认后再应用。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 权重敏感性分析

结果页可对任一价值维度做 0–100% 权重扫描（0.1% 粒度，共 1001 个可达权重），沿用同一方案、时间口径与评分规则复算每个权重下的建议，输出建议区间、并列区间（双色斜纹，不画成唯一胜者）与转折点。其余维度的权重可选择「等比缩放」（保持相对比例，基准为零时回退均摊并提示）或「平均分摊」（触 0 后注水/排水）。

三种转折点寻找方式：

- **智能细化（默认）**：用未取整的分段线性结构穷举所有可能的易主（分差过 0）、并列进出（分差过 ±5）与截断 kink 位置，只在这些位置附近 0.1% 细扫，其余区间由分段线性证明为恒定；含 kink 的格子整格细扫。
- **精确扫描**：全部 1001 点逐点复算，无遗漏，作为正确性基准。
- **固定粗扫（5%）**：对照用，点间标为「未验证间隔」（灰斜纹），直观暴露粗步长对窄并列带与格内折返的遗漏。

所有名次均由规则引擎逐点真实复算，解析公式只用于决定「哪里值得复算」，不做图形插值排名。试探权重仅用于对比，用户确认才写回；重新编辑方案后旧敏感性结论立即标记失效。

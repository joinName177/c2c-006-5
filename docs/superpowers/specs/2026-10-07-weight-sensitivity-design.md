# 权重敏感性试探 设计说明

日期：2026-10-07
关联：`2026-10-05-decision-regret-simulator-design.md`

## 1. 目标与边界

结果页新增“敏感性试探”：用户选定一个价值维度，查看该维度的归一化权重在 0–100% 之间变化时，当前方案的“最不后悔建议”在哪些位置发生变化；并可把滑块临时停在任意位置（含转折点），与当前权重下的结果并排对比。试探不修改原权重，只有用户明确点“套用这组权重”才写回并重新推演；方案被重新编辑后，旧敏感性结果立即失效。

硬约束：

- **完全沿用当前方案、时间口径与评分规则**：选项及影响值取自生成当前结果时的快照（不是编辑中的草稿）；时间系数仍为 1/5/10 年三档；指数仍是 `(5-impact)/10 × 归一化权重 × 时间系数 + 不可逆项`，截断到 0–100；总分仍为 1 年 30%、5 年 40%、10 年 30% 加权后四舍五入；前两名差距 `<5` 仍判定为接近、不给出唯一胜者（差距恰好 5 分仍有明确胜者）。
- **不靠图形插值猜名次**：任何位置的名次都由核心评分函数真实计算。图上的分段颜色只是已计算状态的渲染，不允许用像素/线段交点推断胜者。
- **并列区间必须作为一等结果显示**：接近/并列是一种区间状态（“接近：A、B”），与“某选项唯一领先”同级，不强行画成唯一胜者。
- 试探权重不覆盖 `draft.weights`；套用时才写回，并立即按同一规则重新推演。
- 草稿被编辑（选项、影响值、可逆性、权重任何变化）后 `stale=true`，敏感性面板停用并提示旧结果失效，需重新推演。

## 2. 维度联动：其余权重怎么调

提高一个维度必然挤占其余维度。归一化权重记为 w，总和恒为 100；被试探维度记为 t，当前归一化权重为 b，试探位置为 x（0–100，单位 %）。提供三种可解释的分摊方式，用户在面板上显式选择：

1. **其余按当前比例分摊（proportional，默认）**
   `w_t(x)=x`；`w_k(x)=b_k·(100−x)/(100−b)`（k≠t）。
   即其余三维保持彼此相对比例，共同让出/吸收差额。
   退化情形：当 b=100（当前只看 t）时分母为 0，其余三维不存在“原比例”，按均摊处理 `(100−x)/3`，并在界面注明。
2. **固定一个维度承担（locked）**
   指定“承担维度”a：`w_a(x)=max(0, b_a+b−x)`，承担不了的剩余部分（a 被压到 0 之后）按其余两维的当前比例分配；两维也为 0 时均分。x>b 时 a 反向释放权重。承担维度由用户下拉选择，不能是 t 本身。
3. **其余均摊（equal）**
   `w_t(x)=x`；其余三维各为 `(100−x)/3`。

所有路径构造出的权重都为非负、和为 100 的原始向量，再走与正式推演**完全相同**的 `normalizeWeights`（含 1 位小数舍入），所以试探看到的分数就是用户真把滑块设成那样后能复算出的分数。极端端点天然成立：x=0 = 完全不看该维度；x=100 = 只看该维度（其余三维被挤到 0），不会出现全零权重。

## 3. 寻找转折点的方法

### 3.1 评分函数的结构（为什么可以精确求解）

固定选项与某条权重路径后，单个选项在单个时间点的未舍入指数为

`f(x) = C + Σ_k 系数_k · w_k(x)`，系数_k = `(5−impact_k)/10 × 时间系数_k`，C 为不可逆修正项。

三种路径下 w_k(x) 在 [0,100] 上都是**分段仿射**（locked 方式在承担维度触 0 处有一个折点），因此 f(x) 分段仿射。名次只可能在以下位置改变：

- 分段仿射的折点（locked 承担维度触 0）；
- f 触及截断边界 0 或 100；
- f 跨过半整数 m+0.5（m=0..99）：四舍五入后的整数分在这里跳 1 分。

总分由三个时间点的整数分加权得到，所以在上述所有点之间的每个开区间内，**所有选项的整数总分都是常数，名次状态恒定**。把这些点全部求出来，区间状态就不可能遗漏。

### 3.2 方法 A：固定步长扫描

在 0, δ, 2δ, …, 100 上逐点真实计算名次，相邻两点状态不同就报一个转折。

- 计算量：约 `100/δ+1` 次评分，与方案本身复杂度无关。
- 遗漏：宽度小于一个步长的区间会被整段跨过（窄的并列带、两次相邻翻转 A→B→A 都看不见）；转折位置误差最多一个步长。
- δ=1 时约 101 次评估；δ=0.1 时约 1001 次。计算量与精度线性对冲。

### 3.3 方法 B：逐步细化（粗扫 + 局部加密/二分）

先粗步长扫描；仅在“两端状态不同”的格子内递归二分加密到容差 τ。

- 计算量：转折少时显著省——定位一个转折只需 `log(δ0/τ)` 次二分；无转折区域只付粗扫成本。
- 遗漏：**粗扫看不到的窄区间，细化永远不会去查**——加密只由“已观察到的状态差”触发，盲区由粗步长 δ0 决定而非 τ。也就是说它只提高已发现转折的定位精度，不能发现被粗格整格跨过的区间。对“两端相同、中间不同”的格子无动于衷。

### 3.4 方法 C：结构枚举（本方案采用）

利用 §3.1：在每条仿射段内解出全部候选点（折点、截断交点、半整数交点），合并排序后在每个相邻区间取中点做**一次真实评分**，状态相同的相邻区间合并为一个分段，合并边界即转折点。

- 计算量：候选点数量 = 选项数 × 3 个时间点 ×（约 101 个半整数交点）量级，2–4 个选项时为数百到上千次简单四则运算，且**与想要的分辨率无关**；想显示 0.1% 还是 0.01% 精度，成本不变。
- 遗漏：不漏。任何名次变化必发生在枚举点上，区间内状态恒定有数学保证。窄并列带、窄翻转带都作为分段保留。
- 成立前提：评分规则是分段仿射加舍入（当前规则正是如此）。状态判定仍调用真实评分函数，结构求解只负责“去哪里取样”，不负责“谁赢”——因此不是图形插值。

面板默认使用方法 C；核心层同时导出 A、B 两种扫描器，测试用同一组数据对比三者，固定构造窄区间用例展示 A/B 的遗漏与 C 的命中。

### 3.5 并列与多转折的表示

每个区间的状态分两类：

- `{type:'winner', optionId}`：唯一胜者（与第二名差 ≥5）；
- `{type:'tie', members:[...]}`：领先者与任何差距 <5 的选项组成的接近组（建议文案仍按现有规则点出前两名）。

分段按状态键合并；相邻分段状态不同即一个转折点，输出“当{维度}权重越过 x%：状态甲 → 状态乙”。A→并列→B、A→B→A 等多次转折自然得到多个转折点与中间区间。分段在轴上整条着色，并列段用明确的“接近/并列”纹样与文案，绝不画成单色胜者带。端点 0% 与 100% 分别解释为“完全不考虑该维度”“只考虑该维度”。若整条轴状态不变，明确告知“该维度在 0–100% 内变化都不改变建议”。

## 4. 交互与生命周期

- 入口在结果页：选择维度 → 选择分摊方式（locked 时再选承担维度）→ 展示 0–100% 状态轴、当前权重位置标记、转折点清单与各分段总分/名次。
- 试探滑块：停在任意 x（也可点击转折点/分段直接跳到该位置），下方按**当前快照选项**真实计算试探权重下的指数、总分、建议文案，与当前权重结果并排对比，标出排名互换与分数变化。
- “套用这组权重”：把该位置原始权重写回草稿并立即重新推演（等于用户手动摆滑块后点重新推演）；“还原/放弃”：仅清掉试探，草稿不动。
- 失效条件：草稿任何编辑置 `stale`，敏感性面板停用并提示“方案已修改，旧敏感性结果失效，请重新推演”；重新推演生成新分析对象后面板重置。载入历史案例时按其分析快照恢复。

## 5. 代码结构

- `src/core/scoring.ts`：从 `analysis-service.ts` 抽出的纯评分原语（单点指数、总分排序、接近判定、`analyzeOptions`），正式推演与敏感性共用，规则只有一份。
- `src/core/sensitivity.ts`：权重路径（三种分摊）、状态取样、方法 C 枚举，及方法 A/B 扫描器；全部为纯函数。
- `DecisionAnalysis` 增加 `weights`（推演时的归一化权重快照），作为敏感性基准 b 的唯一来源。
- `src/ui/components/SensitivityPanel.vue`：维度/分摊选择、状态轴（内联 SVG，颜色只来自已计算分段）、转折点列表、试探对比、套用/放弃；props 含 `analysis` 快照与 `stale`。
- `useDecisionStudio`：新增“套用试探权重并重新推演”动作；试探态只存在于组件内。

## 6. 测试

- 权重路径：三种分摊在任意 x 非负且和为 100；x=0/100 端点；b=100 的 proportional 退化；locked 承担维度触 0；equal 端点。
- 结构枚举：每个分段多点取样与真实引擎一致；构造窄区间数据，固定步长（δ=1 等）与粗扫细化均漏掉、方法 C 命中；转折位置与独立细网格交叉验证。
- 并列：差距恰为 5 仍有唯一胜者；差距 <5 的区间显示为 tie 状态；并列带出现在轴上且无唯一胜者。
- 多转折、零权重、极端偏好（x=0、x=100）、全轴无变化均有可解释文案。
- 试探一致性：任意 x 的试探总分 = 用该权重组重新 `analyzeDecision` 的总分；放弃后草稿权重不变；套用后权重写回且结果刷新；编辑草稿后面板失效。
